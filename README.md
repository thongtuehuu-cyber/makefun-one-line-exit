A one-line resignation letter from a zookeeper whose penguins have unionised — written by a deterministic Python program for make.fun's "The One-Line Exit" bounty. `main.py` writes the winning line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (1 line, 116 characters, no trailing newline), validating it first: non-empty, a single line, at most 140 characters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
